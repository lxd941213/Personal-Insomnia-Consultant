# 重置档案确认功能设计

## 概述

在用户点击「重置档案」按钮时，展示底部抽屉确认界面，明确告知用户重置后果，由用户主动确认后才执行重置操作。

## 触发时机

用户点击任意位置的「重置档案」按钮 → 弹出底部确认抽屉（不再直接执行重置）

## 底部抽屉内容

| 区域 | 内容 |
|------|------|
| **标题** | "确定要重置档案吗？" |
| **说明文字** | "重置后以下数据将被永久清除" |
| **数据列表** | 睡眠档案 / 评估记录 / 聊天记录 / 睡眠日记 / 放松记录 / 提醒设置 / 改善计划 |
| **后续提示** | "重置完成后将返回初始页面，您可以重新创建档案" |
| **操作按钮** | 「确认重置」(危险操作，用红色) / 「取消」(中性灰色) |

## 交互行为

- 点击「取消」→ 关闭抽屉，不执行重置
- 点击遮罩层 → 关闭抽屉，不执行重置
- 点击「确认重置」→ 执行重置逻辑，关闭抽屉
- 抽屉打开时背景禁止滚动

## 视觉样式

- 标题字号偏大，醒目的红色警告图标置于标题旁
- 数据列表用圆点+文字，简洁清晰
- 「确认重置」按钮全宽，红色背景白字
- 「取消」按钮全宽，灰色背景
- 抽屉距屏幕底部有一定圆角自然过渡

## 实现位置

- 新建 `src/components/ResetConfirmDrawer.tsx` 作为可复用的确认抽屉组件
- 修改 `DashboardPage.tsx`、`ChatPage.tsx`、`MyPage.tsx` 中的重置按钮逻辑，改为打开抽屉而非直接调用重置函数
- 重置逻辑保持集中在 `App.tsx` 的 `resetProfile()` 中不做变更

## 组件接口

```typescript
interface ResetConfirmDrawerProps {
  isOpen: boolean;
  onClose: () => void;
  onConfirm: () => void;  // 实际执行重置的回调
}
```
