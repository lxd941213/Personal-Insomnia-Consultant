# 项目质量基线优化设计

## 目标

恢复当前项目的测试与构建基线，并让测试、类型接口、文档与当前产品实现保持一致。

## 范围

- 保留当前首页简化实现：首页只展示档案上下文、快速咨询、推荐放松和快捷入口。
- 不恢复已移除的首页 14 天计划卡、今晚待办和首页日记入口。
- 修复因组件接口调整导致的 TypeScript 构建错误。
- 修复因表单文案调整导致的测试失败。
- 清理当前构建明确暴露的未使用导入。
- 更新 README 和中文使用文档中与首页标签、首页内容不一致的描述。

## 设计

### 组件接口

`TodayPage` 不再接收 `onOpenDiary`，`App.tsx` 不再传入该 prop。日记入口保留在底部导航。

`ChatPage` 继续使用 `onOpenResetDrawer` 作为重置确认入口。测试同步使用该 prop，避免重新引入旧的 `onReset` 直连重置接口。

### 档案表单测试

`ProfileWizard` 当前字段文案为「就寝时间」「起床时间」。`App.test.tsx` 同步查询当前可访问标签，测试产品真实文案。

### 文档一致性

README 和 `docs_cn/使用文档.md` 描述当前首页为「首页」标签，并说明 14 天改善计划位于「方案」页面，首页不再直接承载计划任务反馈和提醒待办。

## 验证

- `npm run build`
