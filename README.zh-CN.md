# 个人失眠顾问 H5 MVP

[English](./README.md)

移动端优先的 H5 睡眠健康 AI 顾问 MVP。

## 功能特性

- 本地睡眠档案创建与管理。
- 通过 `POST /api/chat` 进行 AI 睡眠咨询。
- 高风险安全分流与专业评估引导。
- 结构化 AI 回复渲染。
- 本地“有用 / 无用”反馈。
- 仅浏览器本地持久化。
- 睡眠评估（ISI + PSQI-Lite）与风险标记。
- 支持缓存的 AI 睡眠知识卡片。
- 基于场景的咨询入口与提示语。
- 中英文双语能力，当前界面以中文为主。
- 方案页提供 14 天睡眠改善计划，每天一个任务。
- 普通行为任务前先执行确定性安全门控。
- 轻量每日任务反馈与本地进度追踪。
- 在可选 AI 补充前，优先展示可信内置睡眠知识内容。

## 本地开发

```bash
npm install
cp .env.example .env.local
npm run dev
```

在 `.env.local` 中配置以下变量：

```bash
AI_BASE_URL=https://api.openai.com/v1/chat/completions
AI_API_KEY=replace-with-provider-key
AI_MODEL=gpt-4o-mini
```

## 隐私边界

当前 MVP 只在当前浏览器中保存睡眠档案、聊天历史、睡眠日记、任务反馈和本地进度。它不包含账号系统、数据库、云同步或服务端健康档案存储。

AI 回复仅用于健康管理参考，不构成医学诊断。

## 安全与产品边界

本应用是睡眠健康管理与科普陪伴工具，帮助用户记录睡眠、理解可能影响因素、执行保守的自我管理任务，并讨论睡眠管理问题。它不是诊断、治疗、处方、急救或医疗决策平台，也不能替代专业医疗服务。

如果出现自伤或轻生风险、胸痛、呼吸困难、疑似睡眠呼吸暂停并伴随功能受损、药物或酒精依赖、孕期或产后严重睡眠问题、重大疾病信号，或严重失眠并明显影响白天功能，用户应优先联系当地急救服务或线下专业医疗机构。在中国大陆，部分地区可使用当地心理援助或危机干预热线，例如 12356；紧急危险不应等待线上指导。

面向中国大陆用户时，自伤、胸痛、呼吸困难、疑似睡眠呼吸暂停伴功能受损、每晚依赖镇静药或酒精、孕期或产后严重失眠，以及伴随明显白天损害的严重失眠，会在普通行为任务或 AI 生成前被引导至专业评估建议。

## 睡眠改善数据

增强版日记、趋势、放松和方案推荐功能采用本地优先设计。数据通过 `localStorage` 保存在当前浏览器，并带有便于未来同步的 ID 与时间戳；当前版本不包含账号、后端存储、浏览器通知或音频播放。

14 天改善计划在方案页呈现，完成率、连续完成天数、跳过次数和可信知识内容都保持本地优先。普通风险用户可以执行每日任务；高风险档案会在普通行为任务前优先看到专业评估引导。
